LLMと画像生成AIをつないで、テーマから完成漫画まで進む3ステップのワークフローです。Nyamuru🐱 Manga Name Studio（このアプリ）は真ん中に立って、ネーム（OMNY形式）の確認・調整を受け持ちます。

## とりあえず、あなたの創作パートナーのAIに聞いてみる

下の質問文をコピーして、いつも使っているAI（Claude・ChatGPTなど）に貼り付ければ、このアプリのことを案内してもらえます。

```
このリポジトリについて教えて！
https://github.com/sa-san10/nyamuru-manga-name-studio
```

## 作業の流れ

テーマ・原稿 → ネーム（OMNY） → 調整済みネーム → **完成漫画画像**

## STEP 1：LLMでネームを作る

**使うもの**：「生成プロンプト」タブの完全版プロンプト ＋ お好みのLLM（Claude・ChatGPTなど）

1. 「生成プロンプト」タブのプロンプト全文をコピーして、LLMのプロジェクト指示（またはシステム指示）に設定する
2. テーマ・あらすじ・台本と、ページ数や作風などの希望を伝える
3. LLMが出力したOMNY形式のネームを `.yaml` ファイルとして保存する

**できあがり**：OMNY形式のネームファイル（.yaml）

→ [生成プロンプトを開く](#tab-prompt)

## STEP 2：このアプリで確認・調整する（任意・スキップ可）

**使うもの**：Nyamuru🐱 Manga Name Studio（このアプリ）

1. ヘッダーの「読み込み」からSTEP 1のOMNYファイルを開く
2. 「ネーム」タブでコマ割り・人物・フキダシの配置をドラッグで調整し、セリフや演出を手直しする
3. NDM検査でルール違反がないか確かめて、「OMNY保存」からOMNYファイルを保存し直す（画像生成指示分離版と全部入り版を選べます）

**できあがり**：調整済みのOMNYファイル（.yaml）

→ [ネームを開く](#tab-storyboard)

## STEP 3：画像生成AIで漫画にする

**使うもの**：「生成ワークフロー」タブのワークフロー ＋ 「作品情報」タブの画像生成指示（OMAY） ＋ キャラ・背景のリファレンス画像 ＋ 画像生成できるAIエージェント（GPT Workなど）

1. 「生成ワークフロー」タブのワークフローと、「作品情報」タブの画像生成指示（OMAY）を、エージェントが参照できる場所に配置してプロジェクト指示を設定する（初回のみ。以降の作品はOMNYを渡すだけ）
2. OMNYファイルとリファレンス画像を渡して、漫画生成を依頼する
3. エージェントがページ単位で作画・検品・再生成して、完成画像を納品する

**できあがり**：ページごとの完成漫画画像（PNG）

→ [生成ワークフローを開く](#tab-workflow)

## ワンポイントアドバイス

### LLMを使わずにOMNYを一から作ることもできます

Nyamuru🐱 Manga Name Studioがあれば、STEP 1を飛ばしてゼロからのネーム作りも可能です。ヘッダーの「新規作成」でコマ割りパターンを選び、[「ネーム」タブ](#tab-storyboard)でコマ・人物・フキダシを配置して、セリフや演出を書き込めば、そのままSTEP 3へ渡せるOMNYファイルを書き出せます。

### まずは手ぶらで試すなら

このアプリに入っているサンプル漫画をヘッダーの「OMNY保存」でOMNYファイルにして、[「にゃむるたん」タブ](#tab-nyamurutan)の立ち絵画像と一緒にエージェントへ渡せば、STEP 3だけをすぐ体験できます（スタジオを経由せず一枚で完結させたいときは全部入り版が便利です）。

### Claude Codeなら、ネーム設計から納品まで任せられるスキルもあります

姉妹プロジェクトの [rimochan-nyamuru-manga-forge](https://github.com/sa-san10/rimochan-nyamuru-manga-forge) は、「5ページで、こういう話の漫画を描いて」と自然言語で頼むだけで、ネームの設計→作画→検品→納品まで進むClaude Code用スキルです。同じOMNY形式なので、このアプリで整えたネームをそのまま渡して原稿化することもできます。

### 作品固有の画風・ルールはOMAYで作品ごとに管理

作品固有の画風・ルールは、[「作品情報」タブ](#tab-meta)の「OMAYファイルへ書き出し」でその作品用のOMAYファイルとして保存し、作品ごとに管理してください（読み込みも同じタブからできます）。

### スタンドアロン版もあります

CSS・JS・アイコンまで全部入りの単一HTMLファイル版です。ダウンロードしたファイルをダブルクリックするだけで、サーバー不要・オフラインで起動します。USBメモリで持ち運んだり、ネットのない環境でネームを編集したいときにどうぞ。再配布するときは [THIRD_PARTY_NOTICES.txt](/standalone/THIRD_PARTY_NOTICES.txt) を一緒に添付してください。

→ [スタンドアロン版をダウンロード](/standalone/nyamuru-manga-name-studio.html)（スタンドアロン版で開いているときは、代わりに配布元リポジトリ（GitHub）を開きます）
