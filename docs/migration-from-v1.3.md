# v1.3.x からの移行ガイド（v1.4.0〜v1.6.0）

v1.3.x 以前の Nyamuru🐱Manga Name Studio でネームを作り、生成プロンプト・生成ワークフローを AI 側に設定して運用していた方向けの案内です。v1.4.0〜v1.6.0 の変更内容と、手元の環境・ファイルに必要な対応作業をまとめています。

各リリースの詳細は [バージョン履歴](https://sa-san10.github.io/nyamuru-manga-name-studio/changelog) を参照してください。

---

## 変更の全体像

| バージョン | 内容 |
|---|---|
| v1.4.0 | **NDM v10.2**：背景無描画 `bg: -1` の追加、配置の優先順位（action＞anchor＞発言順＝立ち位置＞size＞bbox）の一本化、読み順の正は `bubbles` の配列順のみと明確化 |
| v1.5.0 | **画像生成指示（OMAY）の分離**：作画・演出ルール（`style_notes`）とレイアウト仕様（`layout_spec`）を画像生成指示ファイル **OMAY（Open Manga Artwork YAML）** へ分離。OMNY は作画指示を含まない純粋なネームデータに |
| v1.6.0 | **フキダシ尻尾の運用整理と作品別OMAY**：尻尾は OMAY の指定どおり画像生成時に描画し、人間の後工程はフキダシ内テキスト校正と尻尾の検品に。作品別 OMAY（`(作品名).omay.yaml`）の参照ルールを追加 |

### ファイル構成はこう変わりました

**v1.3.x まで**：ネームデータと作画・演出ルールが 1 ファイルに全部入りでした。

```
(作品名).yaml   ← ネームデータ＋作画・演出ルール＋レイアウト仕様（毎回まるごと AI へ渡す）
```

**v1.4.0 以降**：共通ルールを OMAY に分離し、作品ごとに渡すのはネームデータだけになりました。

```
standard.omay.yaml    ← 共通の作画・演出ルールとレイアウト仕様（画像生成側のプロジェクト指示に一度設定）
(作品名).omny.yaml    ← 純粋なネームデータ（作品ごとに渡す）
(作品名).omay.yaml    ← 作品別の作画ルール（必要な作品のみ。OMNY と一緒に渡す）
```

作品別 OMAY の参照ルール：`(作品名).omny.yaml` と同じ作品名の `(作品名).omay.yaml` があればその作品に適用し、無ければ `standard.omay.yaml` を使用します。

この分離により、生成のたびに定型ルールを転記出力するトークン浪費と転記変異がなくなり、ルール改訂時は `standard.omay.yaml` を更新してプロジェクト指示を貼り替えるだけで全作品に適用されます。

## 対応作業

上から順に進めてください。

### 1. アプリを更新する

- **GitHub Pages（PWA）版**：更新は裏で自動取得されます。起動し直せば新バージョンに切り替わります（1 回の再起動で変わらない場合はもう一度起動）。端末内に自動保存された編集データはそのまま引き継がれます。
- **スタンドアロン版（単一HTML）**：新しいファイルをダウンロードし直してください。

### 2. 画像生成 AI 側のプロジェクト指示を更新する（必須）

AI エージェントのプロジェクト内へ、次の 2 ファイルを配置し直します。

1. **生成ワークフロー本体**（新版）：[agent-manga-generation-workflow.md](../src/content/agent-manga-generation-workflow.md) — 旧版と差し替え
2. **標準OMAY**：[standard.omay.yaml](../src/content/standard.omay.yaml) — 新規に追加。アプリの作品情報タブの「標準テンプレートを保存」ボタンからも入手できます

新しいワークフローは OMAY＋OMNY の 2 ファイル入力構成です。OMNY は作画指示を含まないため、**OMAY を配置しないと作画・演出ルールとレイアウト仕様が不足し、ワークフローは推測で補わず不足報告で止まります。**

### 3. ネーム生成プロンプトを差し替える（必須）

ネーム作成に使う LLM 側へ設定していた生成プロンプトを、アプリの生成プロンプトタブから新版（NDM v10.2 対応）に差し替えてください。

新しいプロンプトは純粋なネームデータ（OMNY）のみを出力します。`meta.style_notes` には作品固有の作画指示（画風の行など）だけが入り、共通の作画・演出ルールは出力されません。

### 4. 既存のネームファイルを更新する

v1.3.x 以前に保存したファイル（ルール全部入りの `.yaml`）もそのまま読み込めますが、次の手順で新形式へ移行してください。

**作品固有の作画ルールを足していない作品：**

1. ヘッダーの「読み込む」で旧ファイルを開く
2. 作品情報タブに出る案内バナーで「NDM v10.2 に更新」を押す（NDM検査の schema_version 警告も解消されます）
3. ヘッダーの「OMNY保存」→「画像生成指示分離版（.omny.yaml）」で保存し直す。以後はこのファイルを作品ごとに AI へ渡します

**作品固有の作画ルール（`style_notes` に独自の行）を足していた作品：**

1. ヘッダーの「読み込む」で旧ファイルを開く
2. 作品情報タブで「NDM v10.2 に更新」を押す
3. 足していた独自の行を控えておく（次の手順で上書きされるため）
4. 作品情報タブの「画像生成指示（OMAY）」セクションで「標準テンプレートを読み込み」を押し、埋め込まれていた旧ルールを最新の共通ルールへ上書きする（上書き確認が出ます）
5. 作画・演出ルール欄へ、控えておいた独自の行を追加し直す
6. 「OMAYファイルへ書き出し」で `(作品名).omay.yaml` を保存する
7. ヘッダーの「OMNY保存」→「画像生成指示分離版（.omny.yaml）」で保存し直す
8. 以後、この作品の生成時は OMNY と一緒に `(作品名).omay.yaml` も渡します

なお「OMNY保存」には従来どおりの**全部入り版（.yaml・ルール込み）**も残っています。1 ファイルで完結させたい場面用で、分離版＋ルールの合成として生成されます。

### 5. 生成時の運用の変化を確認する

| 項目 | v1.3.x まで | v1.4.0 以降 |
|---|---|---|
| 毎回 AI へ渡すもの | 全部入り `.yaml` ＋ キャラクター立ち絵 | `(作品名).omny.yaml` ＋ キャラクター立ち絵（作品別 OMAY のある作品はそれも） |
| 共通ルールの改訂 | 各作品のファイルを個別に修正 | `standard.omay.yaml` を更新してプロジェクト指示を貼り替えるだけ |
| フキダシの尻尾 | 描画を抑制し、人間の後工程で対応 | OMAY の指定（話者の口元へ向ける）どおり画像生成時に描画 |
| 人間の後工程 | フキダシ内テキスト校正・尻尾の対応 | フキダシ内テキスト校正と尻尾の検品（誤った話者へ接続していないかの確認） |

## 新機能：背景無描画 `bg: -1`（対応は任意）

NDM v10.2 で、コマの背景詳細度 `bg` に `-1`（背景無描画）が追加されました。後工程で背景を差し替えるコマ向けに、中間グレー 1 色のベタ塗り・接地影なしで作画する指定です。依頼で指示したコマにのみ使い、演出判断では自動選択されません。既存の `0 / 1 / 2` の意味は変わらないため、使わない場合の対応は不要です。

## 困ったとき

- **旧ファイルを読み込むと NDM 検査に警告が出る** — schema_version が v10.2 でないための警告です。作品情報タブの「NDM v10.2 に更新」で解消します。
- **画像生成 AI が「OMAY が不足」と報告して止まる** — プロジェクト指示に `standard.omay.yaml` が配置されていません。手順 2 を確認してください。
- **OMAY 読み込み時にバージョン不一致の通知が出る** — OMAY の `spec_version` は OMNY の `schema_version` と一致させる運用です。両方を 10.2 に揃えてください。
